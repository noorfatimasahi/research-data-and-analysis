# Research Data and Analysis

## Overview
This repository contains original Web of Science
bibliographic exports for academic research.

## Dataset
The data/raw directory contains five original
Web of Science plain-text export files.

## Data provenance
The original exported records are preserved
without modification.

## Reproducibility
These files are raw bibliographic exports.
They should not be described as the final
PRISMA-screened sample without a verified
screening and inclusion ledger.

## Usage
Use the records for bibliometric analysis
subject to applicable Web of Science licensing
and redistribution conditions.
